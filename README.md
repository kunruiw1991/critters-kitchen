## 🎭 8 种“因果化学反应”与吃播表现 (Zero-Failure Discovery Loop)

1. **💖 完美心愿大满足 (`love`)**：双眼变成旋转金星，脸颊泛红晕，欢呼跳舞；
2. **🔥 喷火辣味反应 (`fire`)**：加入🌶️喷火红辣椒，小脸瞬间涨红，张嘴喷出动画火苗；
3. **🥶 冰晶哆嗦反应 (`ice`)**：加入🍦冰淇淋球，全身变成冰蓝色，头顶结出亮晶晶的雪花冰晶高频发抖；
4. **🍋 极酸表情包反应 (`sour`)**：加入🍋酸柠檬，五官瞬间皱成 `><` 梅花嘴；
5. **💨 黑炭烤焦咳嗽 (`burnt`)**：在平底锅里煎过头烤糊，咬下去“咔嘣”一声吐出黑烟小乌云“咳咳咳”；
6. **🎈 云朵气球飘浮 (`float`)**：加入✨云朵跳跳糖，身体绑上彩色气球飘离座椅在半空晃脚丫；
7. **🌈 彩虹多巴胺变身 (`rainbow`)**：撒上🌈彩虹糖针或混合 3 种以上水果，全身闪烁七彩流光并升起彩虹光环；
8. **😴 香甜吹鼻涕泡秒睡 (`sleepy`)**：🥛热牛奶 + 🍯星星蜂蜜，趴在餐桌上吹起蓝色睡眠泡泡“呼噜噜~ Zzz”。
